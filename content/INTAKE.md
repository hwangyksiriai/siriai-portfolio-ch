# 콘텐츠 인테이크 현황

## 수집 방법 (확인 완료)

샤오홍수 본문은 **브라우저로는 열립니다.** curl/HEAD는 302·404로 막히지만, 실제 브라우저로
게시물을 열면 `window.__INITIAL_STATE__`에 아래가 전부 들어 있습니다.

- 제목(중문 후킹 카피) · 본문 · 해시태그
- 크리에이터 닉네임 · userId
- 발행 시각(epoch ms)
- 이미지 전체 URL / 영상 masterUrl

이미지·영상은 `Referer: https://www.xiaohongshu.com/`를 붙이면 curl로 다운로드됩니다.
**따라서 미디어 파일을 따로 주실 필요가 없습니다.**

### 제약

| 항목 | 상태 |
|---|---|
| 이미지 해상도 | 1080×1440 (서명 URL의 고정 변형본. 다른 변형은 403) |
| 미디어 URL 수명 | 서명·만료형 — 추출 직후 받아야 함 |
| 팔로워 수 | 비로그인이라 **구간값만** (`1만+`, `1천+`). 프로필 조회는 레이트 리밋 잦음 |
| xsec_token | 공유 세션마다 다름. 보안 게이트(`/404/sec_…`)를 거쳐 나온 토큰은 **죽은 토큰** |
